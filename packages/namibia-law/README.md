# Namibia Law

Optional bibliographic add-on for Legal Research. It installs a managed catalogue at `/legal-authority-packs/NA`, not a second research service. The app's launch page preselects Namibia. Upstream: [Lexifina Namibia at the indexed revision](https://github.com/lexifina/namibia-law/tree/e46aaa41315de063236d6df919829a7f6db63cf8); the publication links go to NamibLII. No source wording or editorial commentary is redistributed.

Edit the bibliographic entries in `src/build.mjs`, verify dated snapshots against upstream and regenerate with `npm run build`. Changes in upstream sources do not automatically change installed citations.
