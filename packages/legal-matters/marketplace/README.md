# Legal Matters

Take a **synthetic** commercial instruction from first contact to a reviewed draft invoice. Link CRM parties and aliases, record the human conflict decision, and agree hourly or fixed fees. Bill validated time and individually justified disbursements without copying private work descriptions into client invoices.

**Disabled by default.** Requires a dedicated pilot workspace whose entire membership is cleared for every pilot file. Not suitable for real client data, ethical walls, trust accounting or automatic legal clearance. Install CRM, Project, Timesheets, Expenses and Invoicing with their dependencies. See the package README for setup, reconciliation and release gates.
