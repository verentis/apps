# Smart Editor

Smart Editor adds a text-editing experience for workspace files. Open code or configuration, make changes with Monaco-powered editing, and save back to the workspace.

## What you can do

- Update a JSON or YAML configuration file.
- Edit Python, JavaScript and other supported text files.
- Save from the workspace header or with Ctrl/Cmd+S.

## Before you install

You need read and write access to the selected workspace file. Saving requires a current workspace version that supports the Save action in its header. No external account is required.

## Important limits

Editing a script does not run it: execution requires the appropriate engine and permissions separately. Failed saves leave changes unsaved; edits made during a save require another save. This is not a document-layout or image editor.
