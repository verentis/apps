# Verentis Ocean theme

Cool blue palette with a deep navy sidebar. One of the Verentis off-the-shelf workspace themes: a complete colour palette for light and dark
mode (primary, surfaces, sidebar, charts, shadows and corner radius).

## What it installs

`/.theme/theme.css`, `/.theme/hero` and `/.theme/hero.dark`. The dashboard supergraphic uses blue stripes
matched to the theme palette in light and dark mode. The theme record is created at `themes/verentis-ocean-theme`. Logos, favicon and background
images are not changed.

## Requirements

None. The package has no dependencies, scripts or settings.

## Important limits

Installing replaces the workspace theme. Only one theme is active per workspace; installing another theme replaces
this one, and uninstalling restores the default Verentis theme.
