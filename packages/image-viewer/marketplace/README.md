# Image Viewer

Image Viewer adds a dedicated image-opening experience to your Verentis workspace. Review a picture where it is stored instead of switching to a separate image application.

## What you can do

- Inspect a photo or diagram with zoom controls.
- Rotate the view to read a sideways image.
- Open common image formats from workspace files.

## Before you install

You need a Verentis workspace with access to the image and permission to read its contents. No external account or companion engine is required.

## Important limits

This is a viewer, not a photo editor. Zoom and rotation change the view; they do not retouch, crop or rewrite the original image. Support is limited to the registered image formats and what the browser can display.
