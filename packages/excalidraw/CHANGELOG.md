# Changelog

## 0.1.0

- Nuxt/Vue shell with an upstream Excalidraw React island.
- Workspace launcher, synthetic templates, standard embedded-image documents,
  self-hosted fonts and PNG/SVG/document downloads.
- Bounded document validation, typed native SDK editor adapter, per-element operations,
  participant cursors, receipt-fenced autosave/Save, disconnect pause and cleanup.
- Pinned, vendored source-built native/create-only SDK and synthetic authenticated
  bridge with two real editor islands; live editing remains gated by platform authority.
- Conditional multipart document creation with collision-safe preconditions,
  encoded paths and no unconditional retry; defaults disabled until an explicitly
  verified HTTPS API target is configured for the compatible Node route.
- Exact native-scene manifest intent with least-privilege file capabilities/scopes.
- Bundled MIT/OFL editor/font notices and OFL Liberation font compatibility asset.
