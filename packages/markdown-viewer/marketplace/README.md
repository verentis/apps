# Markdown Viewer

Markdown Viewer opens your workspace Markdown as a readable document. Installation adds a viewer for Markdown files, keeping the original text available alongside the formatted preview.

## What you can do

- Read project notes with tables, checklists and highlighted code blocks.
- Jump between headings with the document outline.
- Switch between Preview and Source; follow workspace-relative links and images.

## Before you install

You need a Verentis workspace and read access to the document and any linked files. Copying the whole document requires a current workspace version that supports actions in its header; browser clipboard permissions still apply.

## Important limits

This package reads Markdown; it does not edit or save it. Raw HTML is sanitised rather than treated as trusted application content. Linked files must remain accessible to you.
